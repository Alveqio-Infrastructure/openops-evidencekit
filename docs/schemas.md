# JSON Schemas

OpenOps EvidenceKit publishes draft 2020-12 JSON Schemas for the two primary
machine-readable artifacts:

- `schemas/evidence.schema.json`
- `schemas/report.schema.json`

The bundled `validate` command uses a lightweight built-in validator so the CLI
does not need a JSON Schema dependency. The schema files are still useful for
editors, CI systems, documentation sites, and downstream tooling.

## Evidence

Evidence files must contain:

- `schema_version`
- `generated_at`
- `metadata`
- `assets`
- `signals`

Signals intentionally allow extension fields so collector authors can add new
domains without waiting for a central schema update.

## Reports

Reports contain:

- `summary`
- `results`

The report schema is stricter because it is generated by EvidenceKit and consumed
by automation.
